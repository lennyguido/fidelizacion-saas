## En una frase

**Vueltita: que tus clientes vuelvan, y saber cuánta plata volvió de verdad.**

## Lo más importante

1. La competencia existe y cobra entre ~$20.000 y ~$95.000 por mes: **hay mercado**.
2. Nadie muestra con honestidad cuánto volvió **por** el sistema. Nosotros sí (grupo de control). Esa es la diferencia.
3. El rival real es la tarjetita de cartón y "no hacer nada": vender con casos y números del barrio.
4. Antes de gastar en logo: **registrar dominio y marca**.
