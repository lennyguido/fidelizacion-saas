# Turnos — recon (replica-recon, versión liviana)

> Solo funciones y flujos, de páginas públicas. Nada de código, textos, logos ni diseño de otros.

## Fuentes
* AgendaPro, página para barberías (Argentina): https://agendapro.com/ar/barberia/software-para-barberias
* Booksy, opiniones de usuarios en Capterra: https://www.capterra.es/software/142741/booksy

## Ciclo principal (lo que se paga)
1. El cliente reserva solo, a cualquier hora, desde un link (Instagram, WhatsApp, web).
2. Elige servicio → profesional (o "cualquiera") → día → horario libre → deja nombre y celular.
3. Recordatorio antes del turno (WhatsApp/mail). Puede cancelar desde un link.
4. El local ve la agenda del día por profesional y marca asistió / no vino.

## Lo que tienen y dejamos para después
Pago adelantado (seña), comisiones por profesional, caja, marketplace, recordatorios automáticos por WhatsApp API.

## Quejas de usuarios (replica-entrepreneur)
* Comisiones por reserva que se cobran aunque el cliente no venga → **acá no hay comisión por turno: precio fijo por mes.**
* Tarda en "aparecer" para clientes nuevos → **el link propio se comparte en Instagram/WhatsApp desde el día 1.**
* La lista de espera no aparece en AgendaPro → candidata a diferencial (siguiente versión).

## Ángulo
"Tus clientes sacan turno solos, sin comisiones por turno, y el que dejó de venir recibe un mensaje": Turnos + la recuperación que ya tiene Neriva.
